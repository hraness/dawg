# Studio v1

Twenty-two small original DAWG sounds, available offline. None of the voice files is a recording of a person. The four short phrases and vowels are DAWG's own formant singer. The three sung hooks and twelve vocal books are Kokoro-82M (Apache-2.0) text-to-speech singing original lyrics, retuned onto original melodies with the WORLD vocoder. No third-party audio or song melody is included.

All files: mono PCM16 WAV, 24 kHz, -6 dB peak, faded file boundaries. The four phrase syllables occupy exact quarter-file regions (0–0.25, 0.25–0.5, 0.5–0.75, 0.75–1), each with a short release gap. They are one bar at 120 BPM. Each sung hook is five bars plus a half-beat lead at its own tempo: line A on beats 0–8, line B on 8–16, and the three chop syllables held for a beat at 16, 17.5 and 19. Its five slices open a quarter beat early, so onset consonants land ahead of the beat. Each of the first four vocal books holds eight verse lines (`v1`–`v8`, four beats each), two pre-chorus lines, three chorus lines (eight beats each), six one-beat chop syllables on A4 and a four-beat held vowel (`hold`), every part rendered separately and opening a quarter beat early; its named slices give each part's file fractions. The three later books keep the same layout but give each line its own length (four to eight beats) and add a low second voice; their `human` setting adds a singer's timing drift and pitch wander. The Candy Fault book has no held vowel: it sings that song's topline line by line (6 to 24 beats each), with its final-chorus lines already a half step up. Hits and sweeps have nominal sampler roots where no single fundamental applies.

Regenerate the first eight from the repository root with `bun scripts/generate-studio-samples.ts`, the sung hooks with `scripts/vox/phrases.py` and the vocal books with `scripts/vox/songs.py` (setup in `scripts/vox/README.md`). Those sources record every voice parameter, oscillator formula, seed, fade and normalization step. `manifest.json` records each file's SHA-256, byte length and duration. The checked-in metadata in `core/bundled-samples.ts` pins the same hashes; changing a published sound requires a new library version and URL namespace rather than silently replacing studio-v1 bytes. Small floating-point library differences can affect regenerated least-significant PCM bits; the checked-in, hash-verified WAVs are the canonical distribution.

`https://dawg.sh/bundled/studio-v1/` is an internal versioned asset identity. DAWG resolves these exact catalogued URLs from its installed package before considering caches or network access. It never fetches missing or unknown assets from that namespace. Packaging must include `assets/samples/**` alongside source modules. No network, speech executable, sample download or account is required.

Manual: `/sample library vocal`, `/sample use hold-on`, `/sample chop hold-on 4`. Agent: `list_packs {pack:"studio"}` returns the metadata and pinned references; `search_sounds {pack:"studio",query:"vocal"}` narrows it; `use_sound {sound:"studio/hold-on"}` loads it. The shared `audio` tool also accepts `input:"pack:studio/hold-on"`; `op:"slice", method:"grid", count:4, track:"chops", pattern:true` creates playable slices in one score revision. Originals are never edited.

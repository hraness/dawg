# Study a reference

Read [reference analysis](../references/reference-analysis.md), [source use](../references/source-use.md)
and [readiness](../references/readiness.md). This workflow produces research, not a cover.

1. Ingest the selected YouTube URL or local audio into the project. Record source
   identity, hash and tool configuration. Reuse existing artifacts only when those
   identities match. Prefer an official upload when choosing a source.
2. Separate stems and analyze the mix. Consume returned artifact paths; never guess
   stem-directory suffixes. Fit the grid to actual onsets and confirm downbeats,
   section entries and repeat lengths. Stem tempo guesses are not authoritative.
3. Measure form, drum/bass presence, groove, register, vocal activity, dynamics,
   frequency bands, filter movement, sustain, stereo width and sidechain depth.
   Distinguish confidence and uncertainty from measured results.
4. Save a project-local ESSENCE document: measurements followed by a short set of
   production decisions that could guide new music. Describe chord vocabulary as
   degrees and principles; do not reproduce a reference melody, riff, lyric lines
   or bar-by-bar chord chart in reusable original-song guidance.
5. If the person asks for a new song, hand only those principles to `original-house`.
   Keep the reference's recordings, stems, note files and reconstruction separate.

There is no automatic export of reference material to public assets. Stock-voice
pitch/tone measurements do not establish an artist's vocal identity.

Run `dawg` in a folder to start a song. Notes fall toward the hit line
as they play, and the prompt sits below. Every change is one undo step,
so try anything.

## Ask

- "make a four bar lo-fi loop at 85 BPM" (needs an agent: `guide agent`)
- The pill by the prompt: NOW sends at once, NEXT waits for the agent

## Type it yourself

- `track drums` · `pattern house` · `add C4 at 0 for 1` · `tempo 120`
- `play` · `pause` · `undo` · `redo`
- Tip: Space on an empty prompt plays and pauses

## Menu

- Ctrl-K: Sound, Voice (sung audio), Effects, Rhythm, Chords and key…

## Keys

- Ctrl-G Jump: tracks, scenes, editors, sounds, parameters and commands
- Ctrl-B Back: return with your draft and selection
- Ctrl-P play mode · Ctrl-K menu · Ctrl-T TAPE
- `?` keys · `/guide` guides · Ctrl-Q NOW/NEXT
- Escape cancels typing or a filter, then backs out; prompt drafts stay
- If the terminal reserves Ctrl-B, use Jump → Back

Run `dawg` in a folder. The highway shows notes; the prompt is below it.
There are three ways in: ask, play, or open the menu.

## Ask
- "make a four bar lo-fi loop at 85 bpm"
- "add a bass line under the chords"

## Type it yourself
- `add C4 at 0 for 1` one note on beat 0, one beat long
- `tempo 120` · `bars 8` · `play` · `pause`
- Space on an empty prompt plays and pauses
- `undo` · `redo` (Ctrl-Z · Ctrl-Y)

## Next
- Ctrl-P plays notes on the keyboard, Ctrl-K opens the menu
- `?` shows the keys for the screen you are on
- `/help` lists commands, `/guide` opens these guides

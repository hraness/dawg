Run `dawg` in a folder. Describe the song you want, watch its tracks
develop,
and listen while the agent keeps working. Configure an agent with `dawg
model key`
or use an installed local model. Saved songs play offline.

## Ask

- “Write bright hyperpop about a phone left on a train”
- “Bring the words forward and give the second chorus a different beat”
- “Recreate the reference audio in my project, with bf_emma singing its
  words”

The current original-song workflow uses our house hyperpop profile. The
first
coherent draft plays automatically. Accepted work stays saved if you
cancel.

## Type it yourself

- Space on an empty prompt plays or pauses
- Ctrl-T shows all tracks; click a track for its horizontal piano roll
- Ctrl-P pins or unpins a track; Follow resumes moving with the agent
- Page Up/Down inspect time; Alt-Left/Right jump between sections
- Enter sends or steers; Escape cancels work; Ctrl-O opens chat
- Ctrl-Z undoes; prompt drafts survive navigation

## Menu

- The player buttons control listening and track inspection

## Keys

- Ctrl-T overview · Ctrl-P pin · Space play/pause · Ctrl-O chat

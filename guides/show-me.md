With show-me on, the agent types dawg commands into your prompt as it
writes them, and each one runs when its line ends. Captions name the
key or fader, so you can do it yourself next time.

## Ask

- "make the reverb wetter and play a C minor arpeggio"
- At the end it says `do it yourself: type …` and the Ctrl-K path

## Type it yourself

- `showme on` (the default) · `showme quiet` no captions or sounds
- `showme off` the agent edits without typing commands

## Menu

- Ctrl-K › Project › agent › show-me

## Keys

- Ctrl-O lists the lines as `agent › …` · Esc stops the agent

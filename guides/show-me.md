The agent types dawg commands into your prompt bar as it writes them;
each runs as its line ends. Captions name the key or fader.

## Ask

- "make the reverb wetter and play a C minor arpeggio"
- At the end: `do it yourself: type …` and the Ctrl-K path

## Type it yourself

- `showme on` (default) · `showme quiet` no captions or sounds
- `showme off` the agent edits without typing commands

## Menu

- Ctrl-K › Project › agent › show-me

## Keys

- Ctrl-O lists the lines as `agent › …` · Esc stops the agent

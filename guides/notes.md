Notes stream toward the hit line; sustains stretch across beats.
Beats count from 0. Each note has an id shown in the receipt.

## Ask

- "add a melody in the last two bars"
- "make the second note longer and quieter"

## Type it yourself

- `add E4 at 2 for 0.5` add a note
- `move <id> to 2.5` · `length <id> 0.25` · `velocity <id> 0.6`
- `remove <id>` delete one note
- `bars 8` · `extend 4 bars` loop length

## View

- `/view focus` one track · `/view all` every track
- Ctrl-O or `/transcript` the history of requests and edits
